Dieses Repository soll eine Ansammlung von Lerninhalten zu der Vermessungstechnik werden. 
Dabei wird der Fokus auf *so wenig möglich, so viel wie Nötig gelegt*, welches auch der Kerngedanke eines jeden Vermessungstechnikers sein sollte.

Ich oder wir, werden also uns Aufgaben und Themen Felder anschauen die immer wieder auftauchen werden, vor allem im Deutschen raum.

Viele Thematiken werden sich auf die Niedersächsische Katastervermessung beziehen, falls Ihr also aus anderen Bereiche/Bundesländer kommt, kontaktiert mich und gestaltet mit.


## Was nutze ich zum Bearbeiten?
Um es einfach zu halten nutze ich [Quartz V4](https://quartz.jzhao.xyz/) welches es mir ermöglicht alle Inhalte in [Obsidian](https://obsidian.md/) zu nutzen und zu HTML zu konvertieren. Alle Inhalte werden nämlich auf meiner Webseite https://quartz.albatroshd.de veröffentlicht.

Falls ihr euch alle Inhalte auf in Obsidian anschauen wollt, dann müsst ihr das Github repository clonen auf eure eigenen Rechner/Smartphone/Laptop.

 ``` git clone https://github.com/AlbatrosHD/WayToVermessung.git```

Oder Ihr ladet euch die ZIP-Datei herunter.
